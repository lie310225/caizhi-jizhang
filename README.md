# 财智记账 (CaiZhi JiZhang)

> 让个人财务管理像企业一样专业 —— 在记账中持续学习财务知识，让每一个人都能成为自己财富的 CEO。

## 项目简介

**财智记账**是一款融合个人记账与财务知识学习的移动 APP 创意方案。传统记账工具只停留在收支流水层面，本项目提出将企业财务管理的**三大报表**（资产负债表、利润表、现金流量表）思路应用到个人财务场景，帮助用户系统化地分析并改进自己的财务管理。

## 在线查看

直接用浏览器打开 `finance-app-proposal.html` 即可查看完整创意方案（自包含页面，无需服务器）。

## 方案亮点

- **三大报表个人化**：自动生成个人版资产负债表、利润表、现金流量表
- **记账 + 学习闭环**：根据用户财务数据推送场景化财务知识，"用中学、学中用"
- **智能建议**：基于数据的个性化财务管理建议
- **成长体系**：财务管理能力评分，持续追踪进步

## 方案结构

| 章节 | 内容 |
| ---- | ---- |
| 1. 创意概述 | 痛点定位、灵感来源、产品形态 |
| 2. 目标用户与痛点 | 用户画像、使用场景、与传统工具对比 |
| 3. 价值与意义 | 商业价值、效率提升、社会价值 |

## 目标用户

- **职场新人**（22-28 岁）：刚独立管理收入，需养成财务习惯
- **年轻家庭**（28-35 岁）：多重重财务压力，需统筹资产配置
- **理财初学者**（25-40 岁）：想通过实践学习财务报表分析

## 技术说明

纯静态 HTML 单页方案，响应式设计，支持手机 / 电脑 / 打印，无任何外部依赖。
